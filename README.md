# 이재현 · 한국공인회계사 (KICPA)

**재무·회계 전문성에 AI의 생산성을 더합니다.**

회계감사·내부회계·가치평가·연결회계·원가분석 실무 경험과 IT·데이터 역량을 바탕으로,
회계·재무 분야의 AI 전환(AX)을 직접 만들고 공유합니다.

> 결과가 매번 같아야 하는 회계 업무에서는 정해진 규칙이 뼈대가 되고, AI는 추론과 판단을 돕는 도구입니다.
